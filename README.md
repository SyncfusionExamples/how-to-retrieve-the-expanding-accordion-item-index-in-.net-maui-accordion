# how-to-retrieve-the-expanding-accordion-item-index-in-.net-maui-accordion

This sample shows how to retrieve the index of the AccordionItem that is expanding (or has expanded) when using Syncfusion's SfAccordion control in a .NET MAUI application.

## Overview

`SfAccordion` renders a list of expandable items. In many real world scenarios you need to know which item is expanding so you can update view-model state, trigger lazy loading, or perform analytics. This README explains a simple, reliable pattern to capture the expanding item and obtain its index in the accordion's Items collection.

**Reference:**

- Syncfusion MAUI Accordion User Guide: [Getting Started with MAUI Accordion](https://help.syncfusion.com/maui/accordion/getting-started)

**Key idea**

When using `SfAccordion` with explicitly declared `AccordionItem` children (or when using a BindableLayout / ItemsSource-driven approach), the expanding item can be discovered from the accordion's events or behaviors. A behavior attached to `SfAccordion` can listen for expansion changes and then locate the item within the parent `SfAccordion.Items` collection to compute the zero-based index. The sample project contains a `Behavior` implementation (see `Accordion/Behavior/Behavior.cs`) and a page (`MainPage.xaml`) that demonstrates the approach.

Minimal contract

- Input: an `SfAccordion` control containing `AccordionItem` elements or items generated by a BindableLayout.
- Output: the zero-based index of the item that is expanding (or expanded).
- Error modes: if the behavior isn't attached or items are virtualized, the index may not be available immediately; consider using item identifiers if required.

## XAML 

Below are representative snippets copied directly from the project's `MainPage.xaml`. They illustrate a non-items-source approach where items are declared inline.

```
<syncfusion:SfAccordion ExpandMode="SingleOrNone">
	<syncfusion:SfAccordion.Behaviors>
		<local:Behavior />
	</syncfusion:SfAccordion.Behaviors>
	<syncfusion:SfAccordion.Items>
		<syncfusion:AccordionItem>
			<syncfusion:AccordionItem.Header>
				<Grid>
					<Label TextColor="#495F6E"
						   Text="Cheese burger"
						   HeightRequest="50"
						   VerticalTextAlignment="Center" />
				</Grid>
			</syncfusion:AccordionItem.Header>
			<syncfusion:AccordionItem.Content>
				<Grid Padding="10,10,10,10"
					  BackgroundColor="#FFFFFF">
					<Label TextColor="#303030"
						   Text="Hamburger accompanied with melted cheese..."
						   HeightRequest="50"
						   VerticalTextAlignment="Center" />
				</Grid>
			</syncfusion:AccordionItem.Content>
		</syncfusion:AccordionItem>
		<!-- additional AccordionItem elements omitted for brevity -->
	</syncfusion:SfAccordion.Items>
</syncfusion:SfAccordion>
```
